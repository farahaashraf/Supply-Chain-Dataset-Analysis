# 📊 Cable Factory Supply Chain Analysis

### DEPI Data Analysis Graduation Project

## 📌 Project Overview

This project focuses on analyzing the end-to-end supply chain operations of an Egyptian cable manufacturing and export factory using **Power BI**.

The goal is to identify operational inefficiencies, monitor key performance indicators (KPIs), and provide actionable insights to improve inventory management, production efficiency, supplier performance, and delivery operations.

## 📂 Dataset Description

**Dataset:** Cable Factory Supply Chain Dataset

The dataset represents supply chain operations from **2021 to 2025**, covering five years of manufacturing and export activities.

It includes 13 interconnected CSV files containing information about customers, suppliers, raw materials, production, inventory, purchasing, shipments, and market prices.

### Data Sources

| Dataset | Description |
|---|---|
| Customers | Customer information, locations, and market segments |
| Suppliers | Supplier details, lead times, and reliability |
| Raw_Materials | Raw material specifications and reorder points |
| Material_Prices | Historical raw material prices |
| Products | Manufactured cable products and categories |
| Customer_Orders | Customer orders and sales transactions |
| Production_Orders | Manufacturing and production activities |
| Shipments | Shipping and delivery operations |
| Export_Documents | Export documentation and transactions |
| Purchase_Orders | Raw material procurement activities |
| Inventory | Inventory levels and stock management |
| Exchange_Rates | Historical currency exchange rates |
| Ref_WB_Annual_Prices | World Bank commodity price benchmarks |

The factory produces **38 cable products across five product families**, including low-voltage power cables, medium-voltage cables, overhead transmission lines, control cables, and solar DC cables.

## 🎯 Project Objectives

- Analyze overall supply chain performance.
- Monitor production efficiency and customer demand.
- Evaluate supplier performance and procurement activities.
- Identify inventory shortages and stock management issues.
- Analyze shipment and delivery performance.
- Examine raw material price trends and their impact on operations.
- Develop an interactive Power BI dashboard to support data-driven decisions.

## 🛠️ Tools & Technologies

- **Power BI:** Data visualization and interactive dashboards
- **Power Query:** Data cleaning and transformation
- **DAX:** KPI calculations and business metrics
- **Data Modeling:** Building relationships between datasets
- **Excel / CSV:** Data sources and initial exploration

## 📈 Expected Deliverables

1. Cleaned and transformed supply chain datasets.
2. Relational data model connecting supply chain operations.
3. Interactive Power BI dashboard with key performance indicators.
4. Business insights and recommendations for improving supply chain efficiency.
